C# Arrays

There are three things you need to understand:

Array
 ├── 1D Array
 ├── Multidimensional Array (2D, 3D...)
 └── Jagged Array
1. One-dimensional array

An array stores multiple values of the same type.

int[] numbers = new int[5];

This creates:

Index:   0    1    2    3    4
Value:   0    0    0    0    0

Array indexes start from 0.

You can assign:

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

Or initialize directly:

int[] numbers = { 10, 20, 30, 40, 50 };

You can also:

int[] numbers = new int[] { 10, 20, 30 };
Length
Console.WriteLine(numbers.Length);

For:

int[] numbers = { 10, 20, 30 };

output:

3

Last index:

numbers.Length - 1
2. Iterating an array
for
for (int i = 0; i < numbers.Length; i++)
{
    Console.WriteLine(numbers[i]);
}
foreach
foreach (int number in numbers)
{
    Console.WriteLine(number);
}

For interviews, know both.

3. Array is fixed-size

This is important.

int[] numbers = new int[3];

You cannot make it 4 elements:

numbers[3] = 40; // ❌ IndexOutOfRangeException

The array's length is fixed after creation.

If you need a dynamically growing collection, you'll normally use:

List<int>

which we'll cover later.

4. 2D Array / Multidimensional Array

A 2D array is basically a rectangular matrix.

int[,] matrix = new int[2, 3];

Means:

2 rows
3 columns

Conceptually:

        Column
         0   1   2
       ┌───┬───┬───┐
Row 0  │   │   │   │
       ├───┼───┼───┤
Row 1  │   │   │   │
       └───┴───┴───┘

Access:

matrix[0, 0] = 10;
matrix[0, 1] = 20;
matrix[1, 2] = 30;
5. Initialize 2D array
int[,] matrix =
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};

Think:

1  2  3
4  5  6
6. Iterating 2D array

You need nested loops:

for (int i = 0; i < matrix.GetLength(0); i++)
{
    for (int j = 0; j < matrix.GetLength(1); j++)
    {
        Console.Write(matrix[i, j] + " ");
    }

    Console.WriteLine();
}
Important interview point

Don't use:

matrix.Length

to determine rows/columns.

Use:

matrix.GetLength(0) // rows
matrix.GetLength(1) // columns

For:

int[,] matrix = new int[2, 3];
GetLength(0) → 2
GetLength(1) → 3
7. Jagged Array ⭐

This is where people often get confused.

A jagged array is:

An array of arrays.

Syntax:

int[][] jagged = new int[3][];

This means:

jagged
  │
  ├── array
  ├── array
  └── array

But the inner arrays haven't been created yet.

You must create them:

jagged[0] = new int[2];
jagged[1] = new int[4];
jagged[2] = new int[3];

Now:

Row 0 → [  ][  ]
Row 1 → [  ][  ][  ][  ]
Row 2 → [  ][  ][  ]

Each row can have a different length.

8. Initialize jagged array directly

You can write:

int[][] jagged =
{
    new int[] { 1, 2 },
    new int[] { 3, 4, 5, 6 },
    new int[] { 7, 8, 9 }
};

Visually:

1  2
3  4  5  6
7  8  9

That's the key feature of a jagged array.

9. 2D vs Jagged Array ⭐⭐⭐

This is an important interview question.

2D array
int[,] matrix =
{
    { 1, 2, 3 },
    { 4, 5, 6 }
};

It's rectangular:

1  2  3
4  5  6

Every row has the same number of columns.

Jagged
int[][] jagged =
{
    new[] { 1, 2 },
    new[] { 3, 4, 5 },
    new[] { 6 }
};

It's not necessarily rectangular:

1  2
3  4  5
6
Easy memory trick
[,]   → rectangular matrix

[][]  → array of arrays
10. How do you get the lengths?
1D
numbers.Length
2D
matrix.GetLength(0)
matrix.GetLength(1)
Jagged
jagged.Length

gives number of inner arrays.

And:

jagged[0].Length

gives the length of the first inner array.

For example:

int[][] jagged =
{
    new[] { 1, 2 },
    new[] { 3, 4, 5 }
};
jagged.Length       → 2
jagged[0].Length    → 2
jagged[1].Length    → 3

You're doing well. 5/6 are essentially correct, but Q6 has an important C# value-type detail. Let's go through them quickly.

1. ✅ Correct
int[]  a;   // 1D
int[,] b;   // multidimensional / 2D
int[][] c;  // jagged

Your wording "jagged array references variables" — better say:

int[][] is an array whose elements are references to other int[] arrays.

That's why each inner array can have a different length.

2. ⚠️ Small correction

For a 1D array:

int[] arr = { 10, 20, 30 };

arr.Length; // 3

For a 2D array:

int[,] matrix = new int[2, 3];

matrix.Length;         // 6
matrix.GetLength(0);   // 2 → rows
matrix.GetLength(1);   // 3 → columns

So yes, you can use .Length with a 2D array, but it gives you the total number of elements, not rows or columns.

Your second question:

Can I use matrix.GetLength(0) for a 1D array?

❌ No.

GetLength() accepts a dimension index, and a 1D array only has one dimension, but you don't access it that way in normal C# usage. For a 1D array, simply use:

arr.Length

For example:

int[] arr = { 10, 20, 30 };

Console.WriteLine(arr.Length); // 3

6. ❌ This one is important

You predicted:

20
30
40

But the actual output is:

10
20
30

Why?

Because:

int[] numbers = { 10, 20, 30 };

foreach (int x in numbers)
{
    x += 10;
}

int is a value type.

x gets a copy of each array element.

Conceptually:

numbers:
[10] [20] [30]
 ↓    ↓    ↓
 x=10 x=20 x=30

Then:

x += 10;

only modifies the local copy.

It does not modify the array.

If you want to modify the array, use an index:

for (int i = 0; i < numbers.Length; i++)
{
    numbers[i] += 10;
}

Now:

20
30
40

This is actually a very useful interview question because it connects:

arrays + foreach + value types + copying.

One important thing to remember

Don't think:

foreach can never modify objects.

For example, with a reference type:

foreach (Employee emp in employees)
{
    emp.Salary += 5000;
}

The emp reference itself is copied, but both references point to the same Employee object, so changing the object's property works.

That's the same value/reference distinction you just learned.
